def quick_sort(arr):
    if len(arr) <= 1:
        return arr
    pivot = arr[0]
    left = [x for x in arr[1:] if x <= pivot]
    right = [x for x in arr[1:] if x > pivot]
    return quick_sort(left) + [pivot] + quick_sort(right)

// JavaScript 快速排序
function quickSort(arr) {
  if (arr.length <= 1) return arr;
  const pivot = arr[0];
  const left = arr.slice(1).filter(x => x <= pivot);
  const right = arr.slice(1).filter(x => x > pivot);
  return [...quickSort(left), pivot, ...quickSort(right)];
}

隐私政策

1. 信息收集

Score AI 不会主动收集、存储或上传任何用户个人信息。所有对话记录仅保存在浏览器本地存储中，不会传输到任何服务器。

2. 数据使用

对话内容仅用于提供即时回复，不会用于任何其他目的。

3. API 调用

发送消息时，输入内容会发送到智谱 BigModel API，通过 HTTPS 加密传输。

4. 本地存储

对话历史仅保存在当前浏览器中，清除缓存可能导致数据丢失。

隐私承诺：Score AI 不会在任何服务器上存储你的对话记录。
